on [make.fun](https://make.fun): a program that writes one funny office line
(1–200 characters) to `/output/entry.txt`.

## The line

> Dave's 9:04 'quick question' ate 47 minutes, so he booked a follow-up to discuss the question — and Karen hit reply-all: 'Can we schedule a meeting about the email we never sent?'

179 characters, 181 bytes. A 3-beat office disaster: the 9:04 "quick question"
that eats 47 minutes, the follow-up booked to discuss it, and Karen's
reply-all kicker — a meeting about the email nobody ever sent.

## Run

```sh
python3 -P -s main.py
```

Writes `entry.txt` to `/output` (override with `OUTPUT_DIR`).
Standard library only, deterministic — every run produces byte-identical output.
